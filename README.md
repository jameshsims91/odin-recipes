# odin-recipes

Recipes
In this project, I was tasked to build a website that contain my favorite recipes to make and eat using just HTML.
I used the terminal to make a new folder in my repos directory for the project called odin-recipes and add an index.html file.
It was also used to make two more folders inside the project folder called images and recipes respectively.
Inside the images folder, I added 3 images of my favorite foods using the correct naming conventions.
Inside the recipes folder, I added the names of my favorite recipes using the extension .html to make separate web pages.
Inside my text editor I was able to link the recipes to my index.html homepage and in each recipe I added a <h1> for the heading/title of the specific recipte. An <img> of the specific food item, <h2> headings for a description and the ingredient and steps portion. The <ul> list was used for the ingredients and the <ol> list was used for the steps needed to make the recipe.
